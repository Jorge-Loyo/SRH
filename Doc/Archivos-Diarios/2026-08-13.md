**Archivo:** `frontend/src/pages/vista_herramientas/DotaneitorPage.jsx`  
**Endpoint:** `POST /api/dotacion/cargos/sincronizar` (ya existe en backend)

**Qué hacer:**
- Después del paso 5 "Guardar en BD" agregar paso 6: **"Sincronizar Dotación"**
- El botón se habilita solo cuando el paso 5 fue exitoso
- Al ejecutar llama a `POST /api/dotacion/cargos/sincronizar`

**Criterio de éxito:** El usuario puede completar el flujo completo Dotaneitor → guardar → sincronizar desde una sola página.

## Notas técnicas

### F11 — endpoints disponibles
```
POST /api/dotacion/cargos/sincronizar  → { insertados, actualizados, cerrados, sin_cambios }
GET  /api/dotacion/cargos/estado       → { total_activos, ultima_sincronizacion }
```
Ambos requieren rol `admin` o `editor`. El frontend ya tiene `altaCargoApi.js` como referencia para agregar las llamadas en `dotacionApi.js` o similar.

### F7 — campo clave en BD
`puestos_cargo.modalidad_tec` — valores: `'pou'`, `'pof'`, `null`.  
Los puestos TEC POU son: Radiólogos, Hemoterapia, Anatomía Patológica, Instrumentadores Quirúrgicos.

### F8 — datos disponibles en respuesta del alta
`POST /api/cargos/alta` devuelve `{ id_alta, codigos[], cantidad }`.  
El tipo y modalidad ya están en el payload enviado — se pueden usar directamente del estado local sin llamada adicional.
